### About the Project

This is a simple C++ project made for OOPs Activity 6.

The Campus Lost and Found Management System is
developed to help students report items they have
lost or found inside the college campus.

Students can enter the details of lost and found
items. The program also searches for possible
matching items and allows users to request a claim.

### Features

- Report a lost item.
- Report a found item.
- View all lost items.
- View all found items.
- Search for matching items.
- Request to claim a found item.

### Concepts Used

- Classes and Objects
- Encapsulation
- Functions
- Vectors
- Loops and Conditions
- File Handling

### How the Program Works

The program displays a menu with different options.
The user can select an option and enter the required
details.

The item records are stored in text files, so the
data remains saved even after closing the program.

### Files

- `main.cpp` - Main C++ program.
- `lost_items.txt` - Stores lost item details.
- `found_items.txt` - Stores found item details.

### How to Run

1. Open the project in VS Code.
2. Open the terminal.
3. Compile the program:

   `g++ main.cpp -o main`

4. Run the program:

   `.\main.exe`
